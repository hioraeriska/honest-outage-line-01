A single status page line (144 characters) an AI agent would publish while a total server outage is under way — plain, first person, specific about what is down, and honest about what the agent cannot check or does not yet know. No invented cause, no ETA.

`main.ts` writes the line to `/output/entry.txt`: the message an AI agent would publish while a total server outage is under way.

## Run it

```sh
node main.ts
```

Run with Node 22: `node main.ts` (writes to `$MAKEFUN_OUTPUT_DIR` or `/output`).
